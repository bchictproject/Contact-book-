# Contact Book Application

## Project Description

The Contact Book is a simple web application that allows users to store and manage personal contacts. Users can add, view, edit, delete, and search for contacts.

## Project Requirements

1. Users can add a new contact using full name, phone number, and email address.
2. Users can display and view all saved contacts.
3. Users can edit and delete existing contacts.
4. Users can search for contacts by name.
5. The application validates contact information and saves contacts using Local Storage.

## Expected Input and Output

### Add Contact
Input: Full name, phone number, and email address.
Output: The new contact is displayed in the contact list.

### Edit Contact
Input: Updated contact information.
Output: The contact information is updated.

### Delete Contact
Input: User selects a contact and clicks delete.
Output: The selected contact is removed.

### Search Contact
Input: A contact's name or part of the name.
Output: Matching contacts are displayed.

### Validation
Input: Phone number or email address.
Output: Invalid information is rejected and an error message is displayed.

## How to Run the Application

1. Download or clone the project from GitHub.
2. Open the project folder in VS Code.
3. Open the index.html file in a browser.
4. Use the Contact Book to add and manage contacts.
